## Master Prompt for Website Generation

> **Copy and paste the following into a tool like Framer, Midjourney (for UI design), or an AI coder (like Cursor or v0.dev).**

**Role:** Senior Web Developer & UI/UX Designer

**Task:** Build a high-end, responsive one-page business website with a "Cyber-Tech" aesthetic.

**1. Visual Identity & Theme:**

* **Style:** Futuristic, tech-focused, and sleek. Use glassmorphism, glowing borders, and a dark-mode-first approach.
* **Color Palette:** Deep blacks and charcoals (#0A0A0A) for backgrounds, with neon cyan and electric violet as accent colors for buttons and highlights.
* **Typography:** Modern sans-serif (e.g., Inter or Orbitron for headers).
* **Mode:** Support both Light and Dark modes using a system-aware toggle.

**2. Layout & Sections:**

* **Header:** Fixed position. Includes a logo placeholder, a Language Switcher (EN, zh-TW, DE), a Theme Toggle, and two navigation buttons ("Product" and "About") that smooth-scroll to their respective sections.
* **Hero Session:** A high-impact section with a bold headline, a value proposition sub-headline, and a "Get Started" CTA. Incorporate a subtle background animation (like a moving grid or floating tech particles).
* **Value Proposition:** Three-column grid highlighting core business benefits with glowing icons.
* **Product/Services:** A showcase area for features using interactive cards that scale or glow on hover.
* **About Us:** A clean session for company history and mission.
* **Footer:** Shared component with site links, social icons, and copyright.

**3. Technical Requirements:**

* **Framework:** Use React with Tailwind CSS and Framer Motion for animations.
* **Internationalization (i18n):** Implement a state-based language switcher supporting EN, zh-TW, and DE.
* **Animations:** Use scroll-reveal effects (fade-in/slide-up) for each section. Ensure buttons have a "holographic" or neon-glow hover state.
* **Responsiveness:** Fully optimized for Mobile, Tablet, and Desktop.

**4. Content Placeholders:**

* **Business Name:** Digicore Technology Limited
* **Value Prop:** "Redefining the digital frontier with cutting-edge solutions."
